# tilabt

**T**oday **I** **L**earning **A**bout — a home for small repositories documenting
things I pick up while building: notes, exercises, and experiments.

- Each repository is self-contained: clone only what you need; there is no monorepo.
- Repos are named after the thing being learned, not the lesson number.
- Code is often deliberately rough: the goal is to understand the concept, not to ship it.

# tilabt

**T**oday **I** **L**earning **A**bout — a home for small repositories documenting
things I pick up while building: notes, exercises, and experiments.

[![topic: til](https://img.shields.io/badge/topic-til-blue)](https://github.com/orgs/tilabt/repositories?q=topic%3Atil)

Every repository is self-contained and tagged
[`til`](https://github.com/orgs/tilabt/repositories?q=topic%3Atil), so that filter is the index.

- Repos are named after the thing being learned, not the lesson number.
- Code is often deliberately rough: the goal is to understand the concept, not to ship it.

More about the idea: [tilabt/tilabt](https://github.com/tilabt/tilabt).
